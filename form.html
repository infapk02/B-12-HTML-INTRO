html form and input tag

html form tag are used to collect information from users and send that information somewhere. for example:

  • login forms
  • registration forms
  • search forms
  • contact forms and so on

the form tag

form tag acts as a container for form controls






the input tag

the input tag give us a input field where we can put our data and submit them. input tag also a empty tag/void tag. input tag have a necessary attribute called type. where we can say the type of the input tag. for example:

  • text
  • password
  • email
  • checkbox
  • radio
  • number
  • date
  • file and so on
