HTML Document Structure

HTML structure means the basic arrangement of elements in an HTML document. Every HTML webpage generally follows a standard structure.

Basic HTML Structure

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>My Website</title>
</head>
<body>

    <h1>Hello World</h1>
    <p>This is my first webpage.</p>

</body>
</html>

Now let's understand each part.

1. <!DOCTYPE html>

<!DOCTYPE html>

This tells the browser:

This document is written using HTML5.

It is called a DOCTYPE declaration.

It is not an HTML element.

Important

<!DOCTYPE html>

It should be placed at the very top of the HTML document.

2. <html> Element

<html lang="en">

The <html> element is the root element of the entire HTML document.

All other HTML elements are written inside it.

<html>
    <!-- Everything goes inside here -->
</html>

lang Attribute

<html lang="en">

lang="en" tells the browser that the page language is English.

For Bangla:

<html lang="bn">

For Bengali websites, you can use:

<html lang="bn">

3. <head> Element

<head>
</head>

The <head> contains information about the webpage. Most of its content is not directly visible on the webpage.

Example

<head>

    <meta charset="UTF-8">

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>My Website</title>

</head>

The <head> commonly contains:

  • <title>
  • <meta>
  • <link>
  • <style>
  • <script>

4. <meta charset="UTF-8">

<meta charset="UTF-8">

This tells the browser which character encoding to use.

UTF-8 supports many languages and symbols, including:

  • English
  • বাংলা
  • 中文
  • العربية
  • 😀

So it is commonly included in every HTML document.

5. Viewport Meta Tag

<meta
    name="viewport"
    content="width=device-width, initial-scale=1.0"
>

This is very important for responsive websites.

It tells the browser:

Make the webpage width equal to the device's screen width.

Without this, a website may not display properly on mobile devices.

6. <title> Element

<title>My Website</title>

The title appears in:

  • Browser tab
  • Bookmarks
  • Search engine results

Example

<head>
    <title>Infa's Portfolio</title>
</head>

The browser tab may show:

Infa's Portfolio

7. <body> Element

<body>
</body>

The <body> contains all the content visible on the webpage.

Example

<body>

    <h1>Welcome to My Website</h1>

    <p>This is a paragraph.</p>

    <img src="image.jpg" alt="A beautiful image">

    <button>Click Me</button>

</body>

Everything the user sees generally goes inside <body>.

Modern Semantic HTML Structure

A professional website often looks like this:

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1.0"
    >

    <title>My Website</title>
</head>

<body>

    <header>
        <h1>My Website</h1>

        <nav>
            <a href="/">Home</a>
            <a href="/about">About</a>
            <a href="/contact">Contact</a>
        </nav>
    </header>

    <main>

        <section>
            <h2>About Me</h2>
            <p>This is the about section.</p>
        </section>

        <section>
            <h2>My Services</h2>
            <p>These are my services.</p>
        </section>

    </main>

    <footer>
        <p>Copyright 2026</p>
    </footer>

</body>

</html>

Important Semantic Elements

<header>

Contains the header area of a webpage.

<header>
    <h1>My Website</h1>
</header>

Usually contains:

  • Logo
  • Website name
  • Navigation menu

<nav>

Contains navigation links.

<nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
    <a href="/contact">Contact</a>
</nav>

<main>

Contains the main content of the webpage.

<main>
    <h1>Welcome</h1>
</main>

A page should generally have one main <main> element.

<section>

Groups related content.

<section>
    <h2>About Us</h2>
    <p>We build websites.</p>
</section>

<article>

Represents independent content.

Examples:

  • Blog post
  • News article
  • Product card
  • Forum post
<article>
    <h2>How to Learn HTML</h2>
    <p>HTML is the structure of a webpage.</p>
</article>

<footer>

Contains the bottom section of a webpage.

<footer>
    <p>© 2026 My Website</p>
</footer>

It may contain:

  • Copyright information
  • Contact information
  • Social links
  • Additional navigation

HTML Element Structure

An HTML element usually has this structure:

<tagname attribute="value">
    Content
</tagname>

Example

<p class="text">
    Hello World
</p>

Here:

  • <p> → Opening tag
  • class="text" → Attribute
  • Hello World → Content
  • </p> → Closing tag

Together, everything is called an HTML element.

Parent and Child Elements

HTML elements can be nested inside other elements.

<body>
    <h1>Hello</h1>
    <p>Welcome to my website.</p>
</body>

Here:

  • <body> → Parent element
  • <h1> → Child element
  • <p> → Child element

Another Example

<div>
    <h2>Title</h2>

    <p>
        This is a paragraph.
    </p>
</div>

The <div> is the parent, while <h2> and <p> are children.

The Most Important Structure to Remember

<!DOCTYPE html>

<html lang="en">

<head>
    <!-- Information about the webpage -->
</head>

<body>
    <!-- Visible webpage content -->
</body>

</html>

Think of it like this:

  • <!DOCTYPE html> → Tells the browser the HTML version
  • <html> → The entire webpage
  • <head> → Information and settings about the webpage
  • <body> → Everything visible to the user
