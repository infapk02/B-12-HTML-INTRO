image tag

the tag is used to display an image on a webpage. image tag is void tag or empty tag.

tag syntax

  • img-> image tag
  • src-> image source/location
  • alt-> alternative text

src attribute

the src attribute tell the where is the image is located

the alt attribute

the alt attribute is used to say some meaningful about the image

if the image is not load successfully then alternative text will say which and what image is that we try to see.
