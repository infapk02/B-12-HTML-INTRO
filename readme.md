# HTML Fundamentals

This repository contains my learning journey and practice files while learning the fundamentals of **HTML (HyperText Markup Language)**.

I created this repository to understand how webpages are structured and how different HTML elements and attributes are used to build web content.

## 📚 What I Learned

### 🔹 HTML Basic Structure

I learned the basic structure of an HTML document, including:

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<meta>`
- `<title>`
- `<body>`

I also learned about the role of semantic HTML elements such as:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

---

### 🔹 Headings and Paragraphs

I learned how to use heading elements from `<h1>` to `<h6>` to create different levels of headings.

```html
<h1>Main Heading</h1>
<h2>Subheading</h2>
<p>This is a paragraph.</p>
```

I also learned how to organize and display text content using paragraph elements.

---

### 🔹 Block-Level and Inline Elements

I learned the difference between **block-level elements** and **inline elements**.

#### Block-Level Elements

Block-level elements generally start on a new line and take up the available width.

Examples:

- `<div>`
- `<p>`
- `<h1>` to `<h6>`

#### Inline Elements

Inline elements generally take only the space required by their content.

Examples:

- `<span>`
- `<a>`
- `<img>`

---

### 🔹 `<div>` and `<span>` Elements

I learned how to use:

- `<div>` for grouping and organizing larger sections of content.
- `<span>` for grouping or styling small parts of inline content.

Example:

```html
<div>
  <h2>About Me</h2>
  <p>This is a section of content.</p>
</div>

<p>This is a <span>special word</span> inside a paragraph.</p>
```

---

### 🔹 Image Tag

I learned how to display images on a webpage using the `<img>` tag.

```html
<img src="image.jpg" alt="Description of the image" />
```

I learned about important attributes such as:

- `src`
- `alt`
- `width`
- `height`
- `title`
- `loading`

---

### 🔹 Anchor Tag

I learned how to create links using the `<a>` tag.

```html
<a href="https://example.com"> Visit Website </a>
```

I learned how to use the `href` attribute to specify the destination of a link.

I also learned that images can be used as links:

```html
<a href="https://example.com">
  <img src="logo.png" alt="Website Logo" />
</a>
```

---

### 🔹 Input Tags and Forms

I learned how to collect user information using forms and different types of input fields.

Examples of input types I practiced:

- Text input
- Password input
- Email input
- Number input
- Radio button
- Checkbox
- Date input
- File input
- Color input
- Range input
- Search input
- Submit input

Example:

```html
<form>
  <label for="name">Name:</label>

  <input type="text" id="name" name="name" placeholder="Enter your name" />

  <button type="submit">Submit</button>
</form>
```

---

### 🔹 Button Tag

I learned how to create buttons using the `<button>` element.

```html
<button type="submit">Submit</button>
```

I also learned about different button types, including:

- `submit`
- `reset`
- `button`

---

### 🔹 HTML Attributes

I learned that attributes provide additional information about HTML elements.

Example:

```html
<img src="image.jpg" alt="A beautiful image" width="300" />
```

In this example:

- `src` is an attribute.
- `alt` is an attribute.
- `width` is an attribute.

I practiced using common attributes such as:

- `id`
- `class`
- `href`
- `src`
- `alt`
- `type`
- `name`
- `value`
- `placeholder`
- `required`
- `disabled`
- `readonly`

---

## 🧠 How I Learned

I learned HTML through a combination of:

1. Understanding HTML concepts and syntax.
2. Studying the purpose of different HTML tags.
3. Practicing each tag with small code examples.
4. Understanding the difference between block-level and inline elements.
5. Creating different types of forms and input fields.
6. Learning how HTML elements are nested inside one another.
7. Practicing HTML document structure.
8. Writing and organizing my own HTML code.

My learning approach was:

> **Learn → Understand → Practice → Build**

I focused on understanding how and why each tag is used instead of only memorizing syntax.
